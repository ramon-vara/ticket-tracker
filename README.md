# ticket-tracker
Command-line ticket tracker built with Python — practicing dictionaries, loops, and functions 
## Features 
- Add a new ticket with title, priority, and auto-generated ID
- view all tickets
- Close a ticket by matching its ID 

## What I Learned
- Searching through a list of dictionaries to find specific item
- Updating a dictionary's value in place a matching condition 
- Building  functions with multiple parameters
- Git basics: staging, committing, and pushing to GitHub

## How to Run
```bash
python3 ticket_tracker.py
```
